Accessibility statement

Last updated 22 August 2026.

Aangan is built to be usable by everyone who runs an Indian household, including people who rely on assistive technology. This statement describes what is supported today, what is not yet verified, and how to reach us.

Supported

  • Dynamic Type: text uses the system’s semantic text styles, so it scales with your iOS text-size setting. The remaining fixed calendar micro-type was replaced with scalable styles for version 1.4.
  • Dark Mode: full light and dark support; colour contrast is checked automatically against WCAG AA in both appearances on every build.
  • Colour is never the only signal: status is always paired with an icon or text label, so meaning does not depend on distinguishing colours.
  • VoiceOver labels: icon-only buttons carry spoken labels that say what they do; charts are paired with a written summary rather than left silent.
  • Reduce Motion: animations soften to fades or none when Reduce Motion is on.
  • Touch targets: interactive controls are sized for comfortable tapping.
  • No flashing content, no autoplaying media, no unexpected sound.

Known limitations (being worked on)

  • A full VoiceOver / Voice Control / Switch Control task pass on physical devices has not yet been completed for every screen.
  • Behaviour at the very largest accessibility text sizes (AX4/AX5) is covered by scalable layouts in source but is not yet verified on the processed TestFlight build across the busiest money screens.
  • The app is English with inline Hindi/Devanagari in places; it is not yet fully localised, and right-to-left layouts are not supported.
  • iPhone only (no iPad-optimised layout yet).

Standard

We target WCAG 2.1 AA and Apple’s Human Interface Guidelines for accessibility. We treat an accessibility defect that stops someone completing a task at the same priority as a functional bug of equal impact.

Contact

If any part of Aangan is hard to use with assistive technology, please tell us by emailing Ateeshay.jain@gmail.com (the support link in the App Store listing); the app’s More ▸ Settings ▸ About section links this statement’s companion policy pages. Describe the screen and the assistive feature you were using, and we will treat it as a real bug.
