# ateeshayjain.github.io

Source of Ateeshay Jain's personal site: a home page, an Apps index and one page per app (Tattvam, Aangan, and Sangrah before its release), each carrying its privacy, terms, support and delete-your-data information. Tattvam's and Aangan's privacy policies and terms live in their own repos (`tattvam-legal`, `aangan-site`); Sangrah's privacy policy and support pages live here, under `apps/sangrah/`, generated from `docs/privacy-policy.md` and `docs/support.md` in the app's repo, whose words they must match. It is plain HTML with one shared stylesheet (`assets/css/site.css`), no build step and no tracking, served by GitHub Pages (`.nojekyll`). `google6bf0be3df5a80368.html` is a Google site-verification file and must stay byte-identical. Run the checks with `python3 tests/check_site.py` (exit 0 means pass); `python3 tests/check_site.py --release` also fails while any `TODO(owner)` placeholder is left.
